# StreamVault v1.2 — Minimal UI + Music Metadata (Windows)

โปรแกรม **Windows Desktop GUI** สำหรับเพิ่มลิงก์ YouTube หลายรายการ แล้วเลือกโหลดเป็น MP3 หรือ MP4 พร้อม **ทดลองฟังตัวอย่างเสียงออนไลน์ก่อนโหลด** และ **เล่นไฟล์หลังดาวน์โหลด** ได้ภายในโปรแกรม ไม่ต้องมี backend หรือ server

## ฟีเจอร์

- Minimal Dark UI ภาษาไทย (PySide6 / Qt) หน้าต่างเดียว ไม่ใช้ Sidebar / มีช่องวาง URL หลายบรรทัดและ Drag & Drop
- อ่านชื่อ ความยาว และภาพปกของวิดีโอก่อนดาวน์โหลด (อาจอ่านภาพปกไม่ได้ในบางเครือข่าย)
- MP3: 128, 192, 256 หรือ 320 kbps
- MP4: สูงสุดที่มี / 2160p (4K) / 1440p / 1080p / 720p / 480p / 360p
- ตั้งชื่อไฟล์ตามชื่อวิดีโอบน YouTube โดยอัตโนมัติ (อักขระที่ Windows ไม่อนุญาตถูกแทนที่; เติม `(2)` หากมีชื่อซ้ำ)
- รายการดาวน์โหลดหลายลิงก์แบบคิวทีละรายการ / แสดงความคืบหน้ารายไฟล์ / ยกเลิกงาน
- **ฟังตัวอย่างก่อนโหลด:** โปรแกรมอ่านสตรีมเสียงจาก YouTube แล้วสร้างคลิป MP3 ชั่วคราว 30 วินาทีเพื่อทดลองฟังใน UI; ไม่ต้องโหลดวิดีโอเต็มก่อน
- **หลังโหลด:** เปิดเล่นไฟล์ที่บันทึกแล้วได้ทั้ง MP3 และเสียงจาก MP4; Play/Pause, Seek, ปรับเสียง
- **ใหม่ v1.2: Metadata MP3**: ฝัง ID3 ชื่อเพลง (ใช้ `track` หาก YouTube มี, ไม่เช่นนั้นใช้ชื่อวิดีโอ), ศิลปิน, อัลบั้ม, ปีที่เพลงเผยแพร่ (เฉพาะฟิลด์ที่มีจริง), ชื่อช่อง YouTube และ URL ต้นทาง
- **ใหม่ v1.2: ภาพปก MP3**: ดึง thumbnail จาก YouTube, แปลงเป็น JPEG และฝังเป็นภาพปก `APIC` ใน MP3 เพื่อแสดงในโปรแกรมเล่นเพลงที่รองรับ ID3
- **ใหม่ v1.2: JPG แยก**: เลือกบันทึกภาพปกเป็น `.jpg` ชื่อเดียวกับไฟล์ MP3 หรือ MP4 ได้
- **ใหม่ v1.2: UI**: มี checkbox เพียง 2 ตัวในส่วนตั้งค่า — `ฝังหน้าปกและข้อมูลเพลงใน MP3` (เปิดเป็นค่าเริ่มต้นสำหรับ MP3) และ `บันทึกหน้าปกเป็น JPG` (เปิดเป็นค่าเริ่มต้น)
- เปิดโฟลเดอร์ไฟล์ที่ดาวน์โหลดได้จากหน้าจอ

## วิธีสร้าง EXE บน Windows 10/11 (64-bit)

> ในไฟล์ ZIP นี้เป็น **source code พร้อมตัวสร้าง EXE** ไม่ใช่ EXE ที่คอมไพล์เรียบร้อยแล้ว เพราะการสร้าง Windows EXE ต้องทำบน Windows

1. ติดตั้ง [Python 3.12 (Windows 64-bit)](https://www.python.org/downloads/) และเลือก **Add Python to PATH** ระหว่างติดตั้ง (3.13 ก็ใช้ได้)
2. แตกไฟล์ ZIP ลงโฟลเดอร์ที่เขียนไฟล์ได้ เช่น `C:\StreamVault` (อย่าเปิด `.bat` จากใน ZIP)
3. ดับเบิลคลิก **`build_windows.bat`** ขณะเชื่อมต่ออินเทอร์เน็ต
4. ตัวสร้างจะติดตั้ง PySide6, yt-dlp, Mutagen, Pillow, PyInstaller, ดาวน์โหลด FFmpeg และ Deno แล้วรวมทั้งหมดเป็นไฟล์เดียว
5. เปิด `dist\StreamVault.exe` (อาจมีข้อความเตือน SmartScreen เนื่องจาก EXE ที่สร้างเองไม่ได้ลงลายเซ็นดิจิทัล)

การ Build ครั้งแรกต้องดาวน์โหลดหลายร้อย MB รวม FFmpeg ประมาณ 109 MB และ Deno พร้อม Qt และ Python dependencies; พื้นที่เก็บข้อมูลต้องเพียงพอ

**ตัวเลือกสำหรับนักพัฒนา:** หากต้องการเปิดเร็วขึ้นหรือ debug แยกเป็นโฟลเดอร์ ให้เรียกจาก PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1 -Onedir
```

ผลลัพธ์ `dist\StreamVault\StreamVault.exe` ต้องย้ายไปพร้อมไฟล์ในโฟลเดอร์เดียวกัน (ต่างจากการสร้างแบบไฟล์เดียว)

## วิธีใช้งาน

1. วาง URL ของ YouTube แต่ละอันคนละบรรทัด แล้วกด **เพิ่มเข้าคิว**
2. โปรแกรมจะอ่านชื่อวิดีโอ ความยาว และภาพปกโดยอัตโนมัติ เลือกรายการที่ต้องการจากตาราง
3. กด **ฟังตัวอย่าง 30 วิ** ในแถบเครื่องเล่นด้านล่าง (ต้องเตรียมตัวอย่างก่อนครั้งแรก)
4. เลือก MP3 หรือ MP4, เลือกคุณภาพ และโฟลเดอร์ปลายทาง
5. ถ้าต้องการฝังข้อมูลเพลง/ภาพปก ให้ทำเครื่องหมายช่อง `ฝังหน้าปกและข้อมูลเพลงใน MP3` และ `บันทึกหน้าปกเป็น JPG` (เปิดไว้แล้วเป็นค่าเริ่มต้น) จากนั้นกด **ดาวน์โหลดทั้งหมด** รายการจะถูกประมวลผลทีละไฟล์
6. สำหรับ MP3 จะมีชื่อเพลงและภาพปกอยู่ในไฟล์ และถ้าเลือก JPG จะมีภาพปกแยกชื่อเดียวกับไฟล์ เช่น `ชื่อวิดีโอ.mp3` + `ชื่อวิดีโอ.jpg` (MP4 ก็เลือกบันทึก JPG ข้างไฟล์ได้)
7. เมื่อสถานะสำเร็จ กด **เล่นไฟล์ที่โหลดแล้ว** ในแถบเครื่องเล่นด้านล่างเพื่อฟังเต็ม หรือกด **เปิดโฟลเดอร์** ด้านบน

## หมายเหตุทางเทคนิค

- ข้อมูลศิลปิน อัลบั้ม และปีที่เพลงเผยแพร่จะว่าง หาก YouTube ไม่ให้ข้อมูลเหล่านี้ โปรแกรม **ไม่เดา** ศิลปินจากชื่อช่อง และไม่ใช้ปีที่อัปโหลดมาแทนปีที่เผยแพร่เพลง
- ภาพปกที่บันทึกเป็น **thumbnail ของวิดีโอ YouTube** ซึ่งอาจไม่ใช่ artwork อัลบั้มอย่างเป็นทางการ และบางวิดีโออาจโหลดภาพปกไม่ได้
- ถ้าเขียนภาพปก/JPG หรือข้อมูล ID3 ไม่สำเร็จ โปรแกรมยังเก็บไฟล์ MP3/MP4 ที่ดาวน์โหลดแล้ว และแสดง `สำเร็จ (ข้อมูลไม่ครบ)` พร้อม tooltip บอกสาเหตุ
- โปรแกรม **ไม่ได้เพิ่มคุณภาพเสียงจากต้นฉบับ** MP3 320 kbps หมายถึง bitrate ของไฟล์ที่แปลง ไม่ใช่ว่าต้นฉบับจาก YouTube มีเสียง 320 kbps
- คุณภาพ MP4 จะขึ้นอยู่กับ source ที่ YouTube ให้ใช้งานจริง และ format ที่ yt-dlp ดึงได้ อาจต่ำกว่าค่าที่เลือกได้; ไม่ใช่ระบบ upscale
- MP4 ที่ใช้สตรีม VP9/AV1 ใน container MP4 อาจมี compatibility ต่างกันใน Windows player เก่า; ในหลายกรณี yt-dlp เลือก MP4/M4A ก่อน
- เครื่องมือ preview สร้างไฟล์เสียงชั่วคราว 30 วินาทีไว้ใน temp directory แล้วลบเมื่อปิดโปรแกรม; ไม่ได้เก็บคลิปถาวร
- การโหลดเพลง/วิดีโอที่ถูกจำกัดอายุ, ภูมิภาค, private, DRM, หรือมีการท้าทายจาก YouTube อาจใช้ไม่ได้ ไม่มีการหลบ DRM และไม่มีการใช้ browser cookies
- ลิงก์ Playlist แบบทั้งชุดยังไม่รองรับ; สามารถวาง **หลายลิงก์วิดีโอเดี่ยว** แทน
- ตัว preview ใช้ URL สตรีมที่ yt-dlp แยกได้; ถ้าล้มเหลวก็ยังสามารถลองดาวน์โหลดตามปกติได้
- ถ้า YouTube เปลี่ยนแปลงรูปแบบข้อมูลในอนาคต อาจต้อง **build ใหม่** ด้วย `yt-dlp` เวอร์ชันใหม่
- ใช้ดาวน์โหลดเฉพาะวิดีโอที่คุณเป็นเจ้าของหรือได้รับอนุญาตให้ดาวน์โหลด และปฏิบัติตามข้อกำหนดของแพลตฟอร์ม

## องค์ประกอบ

- `app.py`: หน้าต่าง Qt, คิวโหลด, preview player และ yt-dlp workers
- `music_tags.py`: อ่านข้อมูลเพลง, แปลง thumbnail JPEG, ฝัง ID3/APIC ด้วย Mutagen, บันทึก JPG ด้วย Pillow
- `tests/`: unit tests ตรวจการตั้งชื่อ, เมทาดาทา และการฝังหน้าปกจริงในไฟล์ MP3 ทดสอบภายในได้ด้วย `python -m unittest discover -s tests -v`
- `requirements.txt`: dependencies
- `build_windows.bat` / `build_windows.ps1`: สร้าง EXE โดยอัตโนมัติ
- `run_source_windows.bat`: รัน source ด้วย environment ที่สร้างแล้ว
- `assets/streamvault.ico`: App icon
- `assets/ui_preview.html` / `assets/ui_preview.png`: ตัวอย่างหน้าตา Minimal UI

## โปรแกรมมี Backend ไหม?

**ไม่มี** ทุกอย่างทำใน Windows เครื่องเดียวโดย `yt-dlp`, FFmpeg, Deno, Qt ไม่ส่งข้อมูลไป backend ของผู้พัฒนา แต่จำเป็นต้องเชื่อมต่อ YouTube เพื่ออ่านสตรีม/ดาวน์โหลด และตัวสร้าง EXE จะดาวน์โหลด dependencies จากแหล่งผู้พัฒนา
